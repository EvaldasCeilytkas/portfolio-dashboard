# Final QA pataisymo diegimas

## Paprasčiausias būdas

1. Pakeiskite dabartinį projekto `src` aplanką paketo `src` aplanku.
2. Pagrindiniame projekto aplanke pakeiskite `package.json`.
3. `public`, `scripts`, Excel ir BAT failų keisti nereikia.
4. Paleiskite:
   - `npm run dev` vietinei patikrai;
   - bendrą BAT failą duomenų atnaujinimui ir publikavimui.

## Pakeisti programos failai

- `src/components/common/AppErrorBoundary.jsx`
- `package.json`

Kiti `src` failai yra paskutinė audituota Performance Audit versija.

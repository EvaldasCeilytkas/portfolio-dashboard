# Portfolio Dashboard Pro v2.0 RC1

RC1 yra stabilizavimo leidimas. Jis nekeičia Excel struktūrų, importerių formulavimo ar portfelio skaičiavimo logikos.

## Nauja

- System Info puslapis (`/system`).
- Duomenų šaltinių diagnostika.
- Naršyklės nustatymų ir Goals konfigūracijos Backup eksportas.
- Release Checklist ir Changelog.
- Puslapių įkėlimas pagal poreikį (`React.lazy`).
- Aplikacijos lygio Error Boundary.

## Diegimas

Pakeisti `src`, `public` ir `scripts` aplankus bei šakninius `vite.config.js` ir BAT failą. Excel failai šiame pakete nekeičiami.

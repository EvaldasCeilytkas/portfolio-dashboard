PORTFOLIO DASHBOARD PRO v2.0 RC1

DIEGIMAS
1. Pakeiskite projekto src aplanką šio paketo src aplanku.
2. Pakeiskite public ir scripts aplankus.
3. Pakeiskite vite.config.js ir ATNAUJINTI_VISUS_PORTFELIUS.bat.
4. Excel aplanko nekeiskite.
5. Paleiskite įprastą BAT failą arba npm run dev.
6. Šoniniame meniu atidarykite System Info.

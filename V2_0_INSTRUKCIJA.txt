PORTFOLIO V2.0 – ĮDIEGIMAS

1. Sustabdykite Vite serverį terminale: Ctrl + C

2. Išarchyvuokite šio ZIP turinį tiesiai į:
   C:\Users\evald\OneDrive\Dokumentai\portfolio-analytics\portfolio-v2

3. Kai Windows paklaus, ar pakeisti esamus failus, pasirinkite:
   Replace the files in the destination / Pakeisti failus paskirties vietoje

4. VS Code Explorer lange patikrinkite, kad matote:
   src\app
   src\components
   src\pages
   src\styles

5. Terminale, kuris atidarytas portfolio-v2 aplanke, paleiskite:
   powershell -ExecutionPolicy Bypass -File .\V2_0_SETUP.ps1

6. Naršyklėje atidarykite:
   http://localhost:5173

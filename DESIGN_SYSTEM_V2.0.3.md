# Design System v2.0.3 — Motion & Polish

- Shared cards use a subtle staggered entrance and 2 px hover lift.
- StatCard numeric values animate from zero when possible.
- Progress bars reveal smoothly from left to right.
- Buttons include press feedback and a restrained highlight sweep.
- DataTable rows gain a gentle hover accent.
- Reusable ToastProvider/useToast and Skeleton components added.
- Sync Center uses skeleton loading and a successful refresh toast.
- prefers-reduced-motion remains fully supported.
